# Coin logos

Token icons from [web3icons](https://github.com/0xa3k5/web3icons) (`@web3icons/core` 4.0.61,
`dist/svgs/tokens/background`), MIT licence. Coin names and logos are trademarks of their owners
and are shown only to identify the coin.

To add a coin: copy its SVG here as `<symbol lowercase>.svg` and add the symbol to `COINS` in
`src/components/coin-avatar.tsx` (the test checks the two match).
